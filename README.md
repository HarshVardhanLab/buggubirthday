# Priya's Little Universe ❤️

A six-scene, mobile-first birthday experience built with Next.js, TypeScript, Framer Motion, and Canvas Confetti.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Add your media

The six supplied photos are installed at these paths; replace any of them with updated images using the same filenames:

- `public/images/her/photo1.jpg` through `public/images/her/photo6.jpg`

Optional: add a music file at `public/music/romantic.mp3`. Playback is user controlled and starts only after tapping the music button.

Edit the messages, captions, dates, and timeline entries in `src/config/birthday.ts`. The memory descriptions are editable examples; update them to your own real memories.
